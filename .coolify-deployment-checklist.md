# Coolify Deployment Quick Reference

## 🚀 Quick Start Checklist

### Before Deployment
- [ ] VPS with Ubuntu/Debian (2GB+ RAM)
- [ ] Domain names configured (optional)
- [ ] Code pushed to GitHub
- [ ] Environment variables prepared

### Installation Order
1. [ ] Install Coolify on VPS
2. [ ] Deploy PostgreSQL database
3. [ ] Deploy Redis cache
4. [ ] Deploy API backend
5. [ ] Run database migrations
6. [ ] Deploy public website
7. [ ] Deploy admin dashboard

---

## 📋 Environment Variables Reference

### API Backend (`apps/api`)

```bash
# Required
NODE_ENV=production
DB_HOST=website-postgres
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=<generate-strong-password>
DB_NAME=website_db
REDIS_HOST=website-redis
REDIS_PORT=6379
JWT_SECRET=<generate-32-char-random>
SESSION_SECRET=<generate-32-char-random>

# Optional (for email functionality)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM=noreply@yourdomain.com

# URLs
FRONTEND_URL=https://admin.yourdomain.com
WEB_URL=https://yourdomain.com
ADMIN_URL=https://admin.yourdomain.com
API_URL=https://api.yourdomain.com
```

### Public Website (`apps/web`)

```bash
NODE_ENV=production
NEXT_PUBLIC_API_URL=https://api.yourdomain.com/api
```

**Build Args:**
```bash
NEXT_PUBLIC_API_URL=https://api.yourdomain.com/api
```

### Admin Dashboard (`apps/admin`)

```bash
NODE_ENV=production
NEXT_PUBLIC_API_URL=https://api.yourdomain.com/api
```

**Build Args:**
```bash
NEXT_PUBLIC_API_URL=https://api.yourdomain.com/api
```

## 🔧 Coolify Application Settings

### API Backend
- **Build Pack:** Dockerfile
- **Dockerfile Path:** `docker/Dockerfile.api`
- **Build Context:** `.`
- **Port:** `4000`
- **Domain:** `api.yourdomain.com`

### Public Website
- **Build Pack:** Dockerfile
- **Dockerfile Path:** `docker/Dockerfile.web`
- **Build Context:** `.`
- **Port:** `3000`
- **Domain:** `yourdomain.com`

### Admin Dashboard
- **Build Pack:** Dockerfile
- **Dockerfile Path:** `docker/Dockerfile.admin`
- **Build Context:** `.`
- **Port:** `3001`
- **Domain:** `admin.yourdomain.com`

## 🌐 DNS Configuration

Add these A records to your domain:

```
Type    Name    Value
A       @       <your-vps-ip>
A       www     <your-vps-ip>
A       admin   <your-vps-ip>
A       api     <your-vps-ip>
```

## 📊 Post-Deployment Commands

### Run Database Migrations

In Coolify API application → Execute Command:
```bash
cd apps/api && npx typeorm migration:run -d dist/config/typeorm.config.js
```

### Seed Database

```bash
cd apps/api && npm run seed
```

### Check API Health

```bash
curl https://api.yourdomain.com/api/health
```

## 🐛 Common Issues & Solutions

### Build fails with memory error
```bash
# Add swap space on VPS
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

### Database connection fails
- Use service names (e.g., `website-postgres`) not `localhost`
- Verify PostgreSQL is running in Coolify
- Check environment variables

### CORS errors
Update API CORS configuration to include your domains

## 🔄 Automatic Deployments

Enable GitHub webhooks in Coolify:
1. Go to each application
2. Settings → Webhooks
3. Enable Automatic Deployment

Now every push to `main` triggers deployment!
